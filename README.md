# 炬鋒CNC ERP（進銷存）

以單一 HTML 檔還原的互動式 ERP 介面，包含：

- **庫存查詢**：庫存主檔（36 筆 S45C 庫存、29 欄）、製程（每品項獨立）、批號 三個分頁
- **銷貨訂單**：訂單表頭、訂單明細（65 欄）、製程明細 分頁
- 所有欄位可直接點選編輯，資料自動儲存於瀏覽器 localStorage
- 右上「還原預設值」可恢復原始資料

## 使用方式

直接開啟 `index.html` 即可，無需安裝任何軟體。

線上版（GitHub Pages）：`https://k22614775-spec.github.io/jufeng-cnc/`

## 注意

- 編輯資料只儲存在「自己這台瀏覽器」，不會跨裝置共用；多人共用需另接後端資料庫（規劃中：Supabase）
